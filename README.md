# web_programming

## 오늘 수정한 사항

- 프로젝트의 핵심 콘텐츠인 추천 여행지 데이터를 국내 여행 트렌드에 맞게 대폭 확장하고 재정비했습니다.
  - 추가: 양양, 가평, 서울, 대전, 대구, 광주
  - 삭제: 도쿄, 다낭
- 추천 여행지 카드와 상세 페이지 대표 이미지를 외부 링크 중심 구조에서 로컬 이미지 중심 구조로 개선했습니다.
  - 예: 서울은 `서울1.png`, 제주도는 `제주도1.png` 형식으로 CSS에서 자동 매칭
  - 이미지 로딩 안정성을 높이고, 여행지별 시각적 구분이 확실해지도록 구성했습니다.
- 여행지 상세 페이지를 단순 정보 화면에서 관광지 탐색까지 가능한 확장형 상세 페이지로 발전시켰습니다.
  - 상세 페이지 하단에 `추천 관광지` 탭을 추가했습니다.
  - 각 여행지의 `spots` 목록을 기반으로 추천 관광지 카드가 자동 생성됩니다.
  - 관광지별 설명 문구를 직접 작성해 사용자가 장소 특징을 바로 파악할 수 있도록 했습니다.
  - `위치 보기` 버튼을 누르면 네이버 지도에서 해당 관광지가 검색된 화면이 새 탭으로 열리도록 연결했습니다.
  - 관광지 사진은 로컬 이미지 파일을 CSS에서 매칭해, JS 데이터 구조를 크게 흔들지 않고 시각 요소를 강화했습니다.
- 상세 페이지 하단에 `추천 숙소` 탭을 추가해 여행지 정보와 숙소 선택 흐름을 자연스럽게 연결했습니다.
  - 기존 숙소 데이터와 연동되며, 상세 페이지에서도 바로 숙소를 선택할 수 있습니다.
  - `이 숙소 선택` 버튼 클릭 시 `선택하신 숙소가 장바구니에 담겼습니다.` 알림이 표시되도록 UX 피드백을 추가했습니다.
- 서울 추천 관광지 데이터를 더 대표성 있는 코스로 다듬었습니다.
  - `성수동`을 `코엑스`로 변경
  - `서울남산타워`, `남산서울타워` 표기를 `남산타워`로 통일
- 지도 기능은 별도 API 키 없이도 동작할 수 있도록 네이버 지도 검색 링크 방식으로 구현했습니다.
  - 무거운 지도 API를 직접 삽입하지 않아 구조가 단순하고 관리가 쉽습니다.
  - 사용자는 추천 관광지에서 바로 위치 검색 화면으로 이동할 수 있습니다.
- 전체적으로 추천 결과, 상세 정보, 관광지 탐색, 숙소 선택이 하나의 흐름으로 이어지도록 페이지 경험을 개선했습니다.
